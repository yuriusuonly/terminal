# Terminal

Web-based terminal emulator.

- [xtermjs](https://github.com/xtermjs/xterm.js) — Terminal front-end component.
- [socket.io](https://github.com/socketio/socket.io) — Fast WebSocket communications.
- [node-pty](https://github.com/microsoft/node-pty) — Fork pseudoterminals.
- [vite](https://github.com/vitejs/vite) — Backend web server and bundler.
